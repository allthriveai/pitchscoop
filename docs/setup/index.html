Choose Your AI Platform:

Claude Desktop RECOMMENDED
✅ Native MCP support, full feature compatibility
⚡ Best performance and reliability
Install Docker Desktop from docker.com
Download/clone PitchScoop to your machine
Copy this configuration to Claude Desktop:
{ "mcpServers": { "pitchscoop": { "command": "docker", "args": [ "compose", "-f", "/path/to/pitchscoop/docker-compose.yml", "exec", "-T", "api", "python", "mcp_server.py" ] } } }
Paste config to: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS)
Restart Claude Desktop completely
Say: "Help me set up PitchScoop" to begin!
ChatGPT with MCP Bridge
⚠️ Community solution, requires MCP bridge installation
🔧 More setup steps, some limitations possible
Install Docker Desktop and Node.js
Install MCP bridge: npm install -g mcp-chatgpt
Configure bridge with this config:
{ "mcp_servers": [{ "name": "pitchscoop", "command": ["docker", "compose", "-f", "/path/to/pitchscoop/docker-compose.yml", "exec", "-T", "api", "python", "mcp_server.py"] }] }
Start bridge: mcp-chatgpt --config config.json
Connect ChatGPT to the bridge
Say: "Set up my pitch competition platform"

Note: See detailed ChatGPT setup guide for complete instructions.
